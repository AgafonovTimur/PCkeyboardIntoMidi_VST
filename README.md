# PCkeyboardIntoMidi

VST3-плагин для Windows: превращает клавиатуру ПК в MIDI-клавиатуру.
Интерфейс нативный (JUCE), без WebView2.

## Как собрать

1. Создайте на GitHub новый репозиторий и загрузите в него всё содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** — сборка запустится сама после загрузки
   (или нажмите **Run workflow** у «Build VST3 (Windows)»).
3. Когда сборка закончится, внизу страницы сборки будет архив
   **PCkeyboardIntoMidi-VST3-Windows**. Внутри — папка `PCkeyboardIntoMidi.vst3`.
4. Скопируйте `PCkeyboardIntoMidi.vst3` в `C:\Program Files\Common Files\VST3`
   и пересканируйте плагины в DAW.

## Подключение в DAW

PCkeyboardIntoMidi загружается как инструмент. В нём выберите MIDI output port,
а в инструменте, которому нужны ноты, — такой же input port.
Ноты уходят по 1-му MIDI-каналу.

## Управление

- Клавиши ПК играют ноты, пока активно окно плагина. Галка «Перехватывать звук вне окна» —
  играть и тогда, когда активно другое окно.
- Раскладки: «Пианино», «Сетка», «Только ноты лада».
- ← → — октава, ↑ ↓ — полутон, пробел — сустейн.
- Нажатие на «Октава», «Полутоны», «Velocity» возвращает значение по умолчанию.
- «Скрыть все настройки» оставляет только клавиши, Esc возвращает настройки.
- Настройки сохраняются вместе с проектом DAW.
